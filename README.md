# 星链祖玛 · Stellar Zuma

一个网页版祖玛(Zuma)游戏,主题取自**恒星光谱分类 O B A F G K M**——七种恒星球的颜色与形态对应从最热的蓝巨星到最冷的红矮星。纯原生 Canvas + WebAudio 实现,零依赖。

## 运行方式

直接双击打开 `index.html` 即可,或启动本地服务:

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 玩法

- 鼠标瞄准,左键点击发射恒星球
- **空格 / 右键** 交换当前球与下一颗球
- 三颗及以上同类恒星球相连即湮灭得分
- 轨道断口两侧同类星球会互相吸引,可引发**连锁反应**(成倍得分)
- 别让星链滚进终点的黑洞,否则游戏结束
- `P` 暂停 · `M` 音效开关

## 七色恒星光谱

| 光谱型 | 名称 | 特征形态 |
| --- | --- | --- |
| O | 蓝巨星 | 四道长衍射星芒 |
| B | 蓝白星 | 十字星芒 |
| A | 白星 | 双层光晕环 |
| F | 黄白星 | 虚线光环 |
| G | 黄矮星 | 八道日冕射线 |
| K | 橙矮星 | 黑子斑纹 |
| M | 红矮星 | 暗面月牙 |

## 关卡

每一关增加一种光谱型(4 → 7 种)、提升链速与球数;清空全部星链即过关,无限递进。

## 技术

- 单文件逻辑 `js/game.js`:弧长参数化螺旋轨道、链球分段物理(推进/回滚/吸附合并)、插入匹配与连锁判定
- 精灵与星云背景均由代码预渲染,无任何图片资源
- 音效由 WebAudio 振荡器实时合成
