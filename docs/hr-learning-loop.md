# 赫罗图读图练习：模型、操作与验证

> 首轮交付记录。**交付状态：完成（2026-10-26）**。独立代码审查的重要发现已修正并复验；最终全套测试 **80/80**、全部 JS 语法检查、差异检查及无注入完整演示通过。布局/遮挡/滚动可达性实测通过；细小文字的真机阅读体验仍待人工试用，不声称像素级逐字审查。

## 本轮目标

让玩家能够暂停祖玛，观察同一套赫罗图中的恒星位置，回答温度、光度和半径问题，根据解释换一个例子再判断，然后回到原游戏流程。

读图练习是**与课程进度无关的可选练习**，与游戏进度完全分开：练习中的正确/错误答案不改变游戏得分、课程点亮和关卡解锁。"本次答对 / 已答"只描述这次作答，不表示已经掌握知识。

本轮不改变原有 17 课、无尽挑战、通关问答与离线 `file://` 运行方式。

## 模块结构

普通 `<script>` 顺序加载（`index.html`）：`js/hr-model.js` → `js/hr-diagram.js` → `js/hr-learning.js` → `js/hr-practice.js` → `js/game.js`。无构建工具、无新增运行依赖；纯逻辑文件同时支持 CommonJS 供 Node 测试。

| 模块 | 全局名 | 职责 | 不做的事 |
| --- | --- | --- | --- |
| `js/hr-model.js` | `StellarHRModel` | 合成教学数据（光谱代表点、区域、演化路径）、对数投影 `project()`、半径换算 `radiusOf()` / `luminosityAtRadius()` | 不接触 DOM、游戏状态或存档 |
| `js/hr-diagram.js` | `StellarHRDiagram` | `render(canvas, scene)` 共享赫罗图渲染（compact/standard/expanded 三档密度、太阳锚点、物理等半径线、甲乙比较星、演化回放）与 `hitTest()` 命中检测；按 CSS 尺寸与 DPR（1–4）绘制 | 不读写游戏状态 |
| `js/hr-learning.js` | `StellarHRLearning` | `createSession()` 纯练习会话：三类题型、确定变体轮换、作答/换题/本次统计；半径判断复用 `Model.radiusOf`，不复制公式 | 不依赖浏览器事件；不触及分数、存档、解锁 |
| `js/hr-practice.js` | `StellarHRPractice` | `mount({getScene, onOpen, onClose})` 独立练习对话层：会话管理、焦点圈闭、背景 inert、`Esc`/`1–3`/`R` 按键 | 不写游戏存档 |

**游戏集成（已实现）**：`game.js` 旧三套赫罗图绘图（`STAR_INFO.hr` 坐标、`LUM_CLASSES` 标记、旧 `EVO_CHAINS` track、手写等半径线、`drawHR/drawProgressHR/hrMap` 等）已全部移除，改由 `getHRScene()` 场景 Adapter 组装 `{progress, target, animation}` 调用共享渲染器（hrMini→compact，hrTitle/hrIntro/hrClear→standard，第二部分附等半径线）；演化动画 track 只保留链/阶段/时间，由共享渲染器绘制；`StellarHRPractice.mount` 全站恰好一次；`H` 快捷键与所有卡片的次级 `data-action="read-hr"` 入口接通；标题选关改用共享 `hitTest`（保留点亮 10 项门条件，光谱点 `i` → 第 `i+1` 关，区域 `i` → 第 `8+i` 关）。

## 数据与科学表达

### 坐标

- 表面温度：K，对数刻度，左热右冷；范围 2,500–100,000 K。
- 光度：L/L☉，对数刻度，下暗上亮；范围 10⁻⁴–10⁶。
- 太阳参照：T=5772 K、L=1 L☉、R=1 R☉。
- 半径关系：`L/L☉ = (R/R☉)² × (T/5772 K)⁴`。
- `project()` 把 (T, L) 归一化：x 左→右、y 上→下；合法但越界的点不夹断，标记 `inside=false` 并在图中以边缘示意呈现；非有限或非正的输入抛出 `RangeError`。

光度是恒星自身辐射的功率，不是站在地球上看到的亮暗；距离不会改变恒星在这张温度—光度图中的本征光度。

### 代表点并非观测星表

主序代表点采用以下**人工合成**教学数据（`js/hr-model.js` 的 `spectral`）：

| 类型 | 温度/K | 光度/L☉ |
| --- | ---: | ---: |
| O | 35,000 | 100,000 |
| B | 18,000 | 800 |
| A | 8,500 | 20 |
| F | 6,500 | 3 |
| G / 太阳参照 | 5,772 | 1 |
| K | 4,500 | 0.2 |
| M | 3,200 | 0.01 |

这些点用于说明主序带上的一般关系，不应将其数值套用于侧栏提到的每一颗真实例星。

### 区域示意范围

区域轮廓同样是人工选取的教学示意（`js/hr-model.js` 的 `regions`），不是精确分类阈值：

| 区域 | 温度范围/K | 光度范围/L☉ | 标记点 (T/K, L/L☉) |
| --- | --- | --- | --- |
| 超巨星区（示意） | 3,000–20,000 | 10⁴–10⁶ | 4,000, 10⁵ |
| 巨星区（示意） | 3,000–8,000 | 30–10⁴ | 4,500, 1,000 |
| 白矮星区（示意） | 5,000–30,000 | 10⁻⁴–0.1 | 15,000, 0.01 |

### 演化示意路径

路径节点为人工选择的合成数据（`js/hr-model.js` 的 `evolution`），节点间隔和动画时长都不代表真实时标：

**类太阳恒星**（7 个节点）：

`(5772 K, 1) → (5500, 10) → (4200, 100) → (3200, 2000) → (30000, 2000) → (100000, 100) → (20000, 0.01)`

课程阶段 4 个，对应第 **0、2、4、6** 个节点：G 型主序星 → 红巨星 → 行星状星云中心星 → 白矮星。

**大质量恒星**（5 个节点）：

`(35000 K, 100000) → (30000, 150000) → (20000, 200000) → (8000, 200000) → (3500, 200000)`

课程阶段 3 个，对应第 **0、2、4** 个节点：主序热端 · O 型星 → 蓝超巨星 → 红超巨星。

其余中间节点只用于路径连线，**不命名、不作为独立课程阶段**。行星状星云阶段的图点表示**中心星**；课程卡沿用原有显示名「抛壳 · 行星状星云」，图表阶段名写作「行星状星云中心星」——两者指同一课程阶段与同一物理坐标点，区分是有意的：卡片名保留课程表述，图表名说明图上实际绘制的对象。大质量恒星的路径不是所有大质量星唯一必经的演化序列。

### 来源用途

概念参考：[OpenStax 光谱分类](https://openstax.org/books/astronomy-2e/pages/17-3-the-spectra-of-stars-and-brown-dwarfs)、[ESA 赫罗图](https://sci.esa.int/web/gaia/-/60240-the-hertzsprung-russell-diagram)、[NASA 恒星类型](https://science.nasa.gov/universe/stars/types/)。这些来源仅用于核对科学概念（光谱型温度顺序、光度类、图中区域分布、演化阶段概念），**不是上述任何合成数值的测量出处**；本项目本轮未建立实测星表。

## 操作与状态契约（已实现）

- **入口**：游玩时用快捷键 `H` 或学习栏「放大赫罗图 · 读图练习」按钮打开。标题、介绍、暂停、过关、失败卡片出现时会物理遮住学习栏，此时侧栏按钮不可达——通过卡片上的次级「读图练习」按钮（非 primary 样式，不替代原主操作）或 `H` 进入。标题与失败画面没有活动课时，以太阳与主序带为阅读参照，不改变所处状态。
- **对话层按键**：`Esc` 关闭；`R` 换一组；`1`/`2`/`3` 按显示顺序选择选项；`Tab`/`Shift+Tab` 焦点限制在练习层内，关闭后焦点返回原处。
- **三类题型**：温度比较（横轴左热右冷，颜色只是提示）、光度比较（纵轴下暗上亮，不是视亮度）、半径推理（依据 L∝R²T⁴，同温时 L∝R²；不以球的绘制大小代替物理半径）。题中的甲/乙为练习示意星；使用"甲/乙"而非"A/B"正是为了避免与 A、B 光谱型混淆。作答后标出正确答案并给出基于坐标或公式的解释；重复点击已答选项不重复计数。
- **统计**：显示「本次答对 X / 已答 Y」，在**整个页面生命周期内累计**——关闭练习层再打开不清零，刷新页面才重置；不写入 localStorage 存档，不改变游戏得分、课程点亮与关卡解锁。
- **冻结与恢复**：打开时释放「按住加速」并冻结游戏更新——星链、发射、技能计时与演化过关动画（含 `frame()` 内的动画推进）全部停止；关闭后回到打开前的状态（从暂停打开，关闭后仍暂停，不跳过原流程）。
- **失焦保护**：阅读期间切换窗口或页面隐藏，只会把底层正在游玩（`playing`）的关卡转为暂停，介绍/问答/终末动画等其他状态不受影响；关闭练习层后保持暂停，等待明确继续，不会意外恢复运行。
- **输入隔离**：阅读期间游戏按键（Space/X/F/P/Enter 等）与指针不穿透；`Esc` 只关闭练习层，不触发游戏暂停切换。原过关问答的选项、反馈与"下一关"解锁状态在开关练习层前后保持一致。

## 演示步骤

以下为仓库自有的演示/验收步骤，可按顺序手工执行（流程：建立存档 → 错答 → 证据 → 换题答对 → 三类题型 → 返回游戏 → 暂停来源 → 失焦 → 刷新）：

1. 直接打开 `index.html`（`file://` 离线可用）。**前置条件**：先确保存在课程存档——完成至少一课的过关问答（点亮进度并解锁下一课），或使用已有存档继续；尚无存档时，刷新后不一定出现「继续游戏」入口。随后开始一关并正常游玩。
2. 按 `H` 打开放大赫罗图，观察星链冻结；按 `Esc` 关闭，确认返回原游戏状态。
3. 再打开读图练习，在温度题先提交一个**错误答案**：反馈应指出甲乙的左右位置与"左热右冷"，并标出正确答案。
4. 按 `R`「换一组」，根据新例子正确作答；重复点击已答选项不能增加作答统计。
5. 切换光度比较和半径推理各答一题：前者依据上下位置，后者依据题设条件与 L∝R²T⁴。
6. 关闭阅读层，确认游戏得分和课程进度没有因练习答案变化。
7. 手动暂停游戏，从暂停卡进入读图练习；关闭后仍应暂停，再点击「继续游戏」恢复。
8. 阅读时切到其它窗口再返回；关闭阅读层后正在游玩的关卡应保持暂停，点击「继续游戏」恢复。
9. 刷新页面：课程存档（点亮进度、最高分、最远已解锁关卡——保存的是课程进度与最佳成绩，不是当前星链的逐帧状态或本次游玩得分）应不受练习作答影响；在步骤 1 已有存档的前提下，标题应出现「继续游戏」入口。
10. 在介绍/过关/失败卡上通过次级入口打开阅读层，关闭后原主操作、问答反馈和解锁状态保持。
11. 在手机尺寸和短横屏窗口重复打开、滚动、作答和关闭，确认没有横向溢出、底层键盘穿透或不可达的按钮。
